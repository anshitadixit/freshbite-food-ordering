# 🍕 FreshBite - Online Food Ordering Website

FreshBite is a modern and responsive online food ordering website developed as a frontend web development internship project.

The website allows users to browse food items, explore restaurants, add food to a shopping cart, complete a simulated checkout process, manage their account, and view order history.
